# PexelApp

PexelApp — это Android-приложение, которое позволяет пользователям искать и просматривать потрясающие, высококачественные стоковые фото и видео, полученные через API Pexels. Благодаря удобному интерфейсу пользователи могут находить бесплатные, не облагаемые роялти медиафайлы, созданные авторами, и использовать их в своих проектах.

## Функции

- **Просмотр высококачественных медиафайлов:** Поиск и изучение разнообразных изображений и видео, полученных через API Pexels.
- **Поддержка пагинации:** Эффективная загрузка больших наборов изображений с помощью Paging3 для плавной прокрутки.
- **Избранное:** Сохранение любимых изображений и видео для быстрого доступа.
- **Поиск:** Легкий поиск изображений и видео по ключевым словам.
- **Офлайн-хранилище:** Использование Room для кэширования и доступа к медиафайлам в офлайн-режиме.

## Технологический стек

- **Android SDK**: Основные инструменты разработки для Android.
- **Jetpack Compose**: Современный UI-инструментарий для создания нативных интерфейсов Android.
- **Jetpack Navigation**: Упрощает навигацию между экранами.
- **Room**: Локальная база данных для кэширования медиафайлов.
- **Retrofit**: HTTP-клиент для взаимодействия с API Pexels.
- **Dagger/Hilt**: Внедрение зависимостей для чистой и модульной архитектуры.
- **Coroutines + Flow**: Асинхронное программирование для плавного и отзывчивого интерфейса.
- **Paging3**: Эффективная загрузка и пагинация больших списков медиафайлов.

## Перед использованием

Чтобы запустить приложение, необходимо сначала добавить свой **API-ключ** Pexels в файл `local.properties`. Получить API-ключ можно, зарегистрировавшись на [Pexels](https://www.pexels.com/api/).

Добавьте следующую строку в файл `local.properties`:
```
API_KEY=your_pexels_api_key_here
```

## Начало работы

### Предварительные требования

Чтобы запустить проект локально, убедитесь, что у вас установлены:

- Android Studio
- Физическое устройство Android или эмулятор
- Активное интернет-соединение для загрузки медиафайлов с API Pexels

### Установка

1. **Клонируйте репозиторий:**

    ```bash
    git clone https://github.com/dragoosha/PexelApp.git
    ```

2. **Откройте проект в Android Studio:**
   - Откройте склонированный репозиторий в Android Studio и дождитесь синхронизации зависимостей.

3. **Добавьте API-ключ Pexels:**
   - Как указано ранее, добавьте ваш API-ключ в файл `local.properties`.

4. **Запустите приложение:**
   - Подключите устройство Android или запустите эмулятор и запустите приложение через Android Studio.

## Использование

1. **Обзор медиафайлов:** Просматривайте популярные фотографии, видео и категории.
2. **Поиск медиафайлов:** Используйте строку поиска для нахождения изображений и видео по ключевым словам.
3. **Сохранение в избранное:** Сохраняйте понравившиеся изображения и видео для быстрого доступа.
4. **Офлайн-режим:** Просматривайте ранее сохраненные медиафайлы без подключения к интернету.

## Как это работает

Приложение интегрируется с API Pexels для загрузки высококачественных изображений и видео по запросу пользователя. Оно использует **Paging3** для загрузки данных частями и эффективного отображения результатов.

Ключевые компоненты приложения:

- **Retrofit**: Выполняет сетевые запросы для загрузки медиафайлов с Pexels.
- **Room**: Кэширует изображения и видео локально для офлайн-доступа.
- **Coroutines + Flow**: Обеспечивает асинхронные сетевые запросы и работу с базой данных для плавной работы UI.
- **Dagger/Hilt**: Управляет внедрением зависимостей, сохраняя код чистым и модульным.
